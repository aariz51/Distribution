## 2. Per-script deep dives

### facetrack.py
- Algorithm: seek once to `--start`, read sequentially at stride `fps/sample_fps` (`facetrack.py:55-59`), downscale to 480 px wide (`:62-65`), YuNet detect (`cv2.FaceDetectorYN.create(model,"",(320,320),0.6,0.3,5000)` `:233`), pick face by `conf + 6*area − 1.5*drift` (`:25-47`). Camera cuts = jump > 25 % of crop width (`:100-108`, `:257`). Moving-average smoothing that never crosses cuts, window ≈1.5 s (`:111-126`, `:260`). Keyframe reduction with deadzone `max(4, out_w*0.015)`, cap 48 keys, cuts protected (`:129-172`, `:282-291`). Static mode when total travel ≤ 6 % of `out_w` (`:275-280`).
- Model: `A/face_detection_yunet_2023mar.onnx` (232,589 bytes) passed via `--model`.
- Output plan: `{"mode":"static","out_w","out_h","samples","coverage","cuts","x","y"}` or `{"mode":"dynamic",...,"x_expr":"max(0\,min(in_w-out_w\,if(lt(t,T1),X0+(slope)*(t-T0),...)))","keys_x":N,"y_expr"/"y"}` (`:175-190`, `:267-297`). The expression is an ffmpeg `crop` x/y expression in `t`. Coverage < 0.15 or < 3 samples → `mode: none` (`:246-248`).

### captions.py + caption_styles.py + caption_styles.json
- **Two renderers**: (a) legacy built-in `STYLES` dict — 7 styles `classic-outline, modern-box, minimal-shadow, vibrant-cyan, vibrant-yellow-box, vibrant-green, vibrant-red` with **hardcoded RGBA** fill/stroke/box and y-fraction (`captions.py:38-46`); one PNG per unique chunk text, cached (`:218-227`); (b) "studio" path — if `spec.style` is one of the 36 JSON preset ids, `render_studio` renders an *animated* sequence at `STUDIO_FPS=12`, max 48 frames per chunk (`:120`, `:123-165`).
- Output is not ASS and not drawtext: it is a **PNG sequence + ffmpeg concat list** (`file '…'\nduration …`) (`:156-161`, `:253-259`) composited with `overlay` because Homebrew ffmpeg lacks `drawtext` (`:1-10`; `SETUP.md:49-80`). The Rust side still keeps a `drawtext` fallback and writes an `.srt` sidecar (`src-tauri/src/lib.rs:1036-1070`).
- Chunking happens in Rust (`src-tauri/src/captions.rs:116`), spec carries `assets` dir (`captions.rs:214-223`).
- Fonts: `captions.py:25-34` (Arial Bold / HelveticaNeue on macOS, `arialbd.ttf` Windows, DejaVu/Liberation Linux); `caption_styles.py:28-46` maps studio families (inter, outfit, poppins, montserrat, roboto, bebas neue, anton, oswald, archivo, courier, georgia) to installed faces; families in the JSON **not** in the map (`Playfair Display`, `Lato`, `Raleway`, `Impact`/`Arial Black`) fall to `FALLBACK_FACES` (`:46`). Size scale `k = height/640` (`:199`); stroke ×1.4 (`:211`).
- **All 36 preset ids** (`caption_styles.json`): basic, revid, ali, wrap1, wrap2, faceless, elegant, difference, opacity, playful, bold-punch, movie, outline, cove, beat, floating, hormozi-pop, karaoke-yellow, beast-bounce, meme-flicker, neon-glitch, color-swap, underline, clean-motion, bubble, double-take, pixel-pop, glass, deep-glow, zero-gravity, cinematic, black-punch, creator-clean, skool, top-bar, chunky. Each carries `fontSize, lineHeight, fontFamily, fontWeight, textTransform, letterSpacing, textColor, backgroundColor, highlightColor, strokeColor, strokeWidth, verticalAlign, horizontalAlign, paddingX, paddingY, borderRadius, positionX, positionY, animation, effect, transition, transitionScope, transitionSpeed` (`caption_styles.json:3-28`).
- **Colour parameterisation verdict**: the studio path is fully data-driven — `parse_color()` accepts `#RGB/#RRGGBB/#RRGGBBAA/rgba()` (`caption_styles.py:98-120`) and reads `textColor/highlightColor/strokeColor/backgroundColor` per preset (`:208-212`). Brand-colour injection = override those four keys on the chosen preset dict before `render()`. The legacy 7 styles are hardcoded and must be re-expressed as presets. Animations supported: fade-in, zoom-in, slide-up/down/left/right, shrink, bouncy, word-bounce, beat, floating, glow, flicker, glitch-pop (`:140-186`); word-level: word-pop, word-bounce, karaoke, color-swap, highlight (`:137`). Effects: shadow variants, stack, glow/neon/subtle-glow, glitch (`:264-267`, `:320-328`). `difference`, `outline`, `lower-stroke` effects present in JSON but **not implemented** in `render()` (silently ignored). `transition*` fields are ignored.
- The frontend style picker only offers the **7 legacy ids** (`src/main.tsx:1938-2013`); the 36 presets are reachable only via `project.caption_style` string.

### title_bar.py
- Faces probed at 28 evenly spaced timestamps via ffmpeg PNG pipe (`title_bar.py:44`, `:123-128`), YuNet swept at 720/480/320 widths (`:121`), score ≥ 0.80 (`:59`). Banner must end above `topmost_face − 2 %` (`:259`).
- Rendering: text-only, **no plate** (`:220-233`): white fill `(255,255,255,255)`, stroke black `(0,0,0,235)` width `size*0.085`, shadow `(0,0,0,140)` offset — **all hardcoded**; UPPERCASE (`:183`), starts at 9.5 % height (`:53`, `:188`), max 2 lines, font shrinks from `height*0.045` by 4 px to `MIN_FONT=34` (`:191-215`), max 20 % of frame (`:48`).
- Two composition modes: `overlay` (draw on picture) or `band` (crop bottom, pad top, so the picture shifts down under the title) (`:262-310`). Adds `unsharp=5:5:0.7:5:5:0.0` sharpen in both modes (`:299`). Encode `libx264 -preset slow -crf 16`, audio copied (`:312-321`).
- Title text itself is written by Rust with Anthropic (`src-tauri/src/title.rs:61-91`), fallback to hook.

### clean_source.py + blur_women.py
- "Cleanup" = (1) never map subtitle streams (`clean_source.py:311`); (2) detect a burned-in caption band by Canny edge density per 12 horizontal strips across 24 samples, lower half only, peak ≥ 1.55× median, shoulder 1.12× (`:38-56`, `:74-169`); if band bottom > 0.86 → **crop it off**, else **boxblur** the strip (`:247-266`); (3) audio: **always** run Demucs `htdemucs --two-stems vocals` (`:192-197`), fallback band-pass `highpass 180 / lowpass 6500 / afftdn / dynaudnorm` (`:207-213`); the isolated vocal replaces the original track entirely (`:299-309`). Invoked on every YouTube download (`src-tauri/src/lib.rs:1316-1321`).
- `blur_women.py`: YuNet at 720/480/320 + GoogleNet gender; anything with male prob < 0.75 is blurred (`blur_women.py:35`, `:152-153`); boxes held 0.6 s, padded 35 % (`:40-42`), merged over time (`:168-190`), ffmpeg crop→boxblur→overlay with `enable=between(t,…)` per region (`:229-249`).
- **Content-policy implication**: `blur_women.py` (docstring `:3-7`), `broll_pipeline.py` `BROLL_PEOPLE_POLICY=no-women` default (`:301-304`, `:416`) and `voice_pick.py` female-preference (`:4-5`) encode a religious-practice constraint via automated gender classification of faces. This is user-specific behaviour, not a general product feature; in a multi-tenant web product it must be an explicit opt-in profile setting (and the gender-classifier default should be `off`). ## 4. Batch / automation shell scripts

None of these drive Claude/Codex *sessions*; they drive **Rust `#[ignore]` integration tests as a headless batch runner**, and poll the Anthropic API to time work around the Claude subscription's 5-hour quota window.

- `run_until_reset.sh` (52): reads `anthropic-ratelimit-unified-5h-reset` / `7d-reset` headers to compute `STOP_AT_EPOCH` (`:17-45`), refuses to run open-ended if unknown (`:40-43`), then `render_parallel` with `BATCH_CONCURRENCY=4` (`:47-52`).
